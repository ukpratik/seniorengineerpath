# Contributing

Thank you for helping. The most useful contributions are **corrections**: a wrong fact, a broken link, an unclear sentence.

## Report a mistake
Use "Report a mistake" at the end of a lesson, or open an issue with the `content-mistake` label. Say what is wrong and, if you can, link a source that shows the right answer.

## Pull requests
1. Read the lesson rules in [`docs/content-guide.md`](docs/content-guide.md).
2. Keep the simple-English rules: short sentences (never over 35 words), common words, no idioms.
3. Every new fact needs a source in the lesson's `sources` and a `[@source-id]` citation.
4. Run `npm run gate` and `npm test` before you open the PR.
